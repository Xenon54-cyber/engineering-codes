# Модели тепловых схем и анализ чувствительности

Данный репозиторий содержит модели тепловых схем с рекуперацией и рекомпрессией, а также модель теплофикационного контура АСММ.

## Рабочие тела и свойства
*   **Цикл Брайтона:** В качестве рабочего тела используется сверхкритический CO2.
*   **Контур реактора и теплофикации:** В качестве рабочего тела используется жидкий натрий.

### Особенности расчета свойств:
*   **CO2:** Свойства определяются через библиотеку **CoolProp**.
*   **Натрий:** Свойства задаются вручную, так как не предусмотрены в стандартной библиотеке.

## Состав моделей
Модели содержат стандартные блоки термодинамических вычислений, расширенные характеристиками потерь:
*   Механические потери;
*   Электрические потери;
*   Тепловые потери.

## Анализ чувствительности
В репозитории представлены коды для проведения анализа влияния различных параметров на работу схемы, в том числе:
*   КПД турбины и компрессора;
*   Минимальный температурный напор;
*   Потери давления.

## Визуализация
Репозиторий включает в себя коды построения графиков, предназначенные для:
*   Оптимизации;
*   Анализа чувствительности.
