# Памятка по построению графиков

Этот стандарт применяется для графиков моделей He–Xe и анализа чувствительности.

## Размер и экспорт

Для слайдов используйте горизонтальный кадр `5 × 3` дюйма (`width × height`).
Не применяйте `bbox_inches="tight"`: он меняет заданный размер рисунка и может смещать подписи в редакторах SVG/PDF.

```python
FIGURE = {
    "size": (5.0, 3.0),
    "dpi": 300,
    "formats": ("png", "pdf", "svg"),
}

fig, ax = plt.subplots(figsize=FIGURE["size"], layout="constrained")
fig.savefig(path, dpi=FIGURE["dpi"], facecolor="white", bbox_inches=None)
```

## Шрифт и оси

- Шрифт: Times New Roman.
- Заголовок: 11 pt; подписи осей: 10 pt; деления: 8 pt; легенда: 7.5 pt.
- Деления направлены внутрь, показаны на всех сторонах осей.
- Основные и вспомогательные деления обязательны; сетка — тонкая, светло-серая.
- Единицы указываются в подписи оси, а не в заголовке.

```python
mpl.rcParams.update({
    "font.family": "Times New Roman",
    "axes.titlesize": 11.0,
    "axes.labelsize": 10.0,
    "xtick.labelsize": 8.0,
    "ytick.labelsize": 8.0,
    "legend.fontsize": 7.5,
    "xtick.direction": "in", "ytick.direction": "in",
    "xtick.top": True, "ytick.right": True,
    "pdf.fonttype": 42, "svg.fonttype": "none",
})

ax.xaxis.set_minor_locator(AutoMinorLocator())
ax.yaxis.set_minor_locator(AutoMinorLocator())
ax.grid(alpha=0.18, lw=0.5)
```

## Линии, маркеры и легенды

- Основная линия: 1.4–1.5 pt.
- Используйте цвет для серии и форму маркера для типа данных.
- Легенда размещается внутри поля графика, где она не закрывает данные; рамка белая, тонкая, прямоугольная.
- Для сравнения модели и справочных данных: расчёт — сплошная линия, справочные данные — открытые маркеры того же цвета.

```python
ax.plot(x, y_model, color="#1F77B4", label="Расчёт, 2 МПа")
ax.scatter(x_ref, y_ref, marker="o", s=27, facecolors="white",
           edgecolors="#1F77B4", linewidths=1.0,
           label="Справочные данные, 2 МПа", zorder=4)
ax.legend(loc="best", frameon=True, framealpha=0.96,
          facecolor="white", edgecolor="0.65", fancybox=False)
```

## Контурные карты

- Цветовая шкала располагается справа, с подписью величины и единиц.
- Изолинии — чёрные, полупрозрачные, с подписями только там, где они не перекрывают данные.
- Оптимум отмечается красной звездой с белой обводкой.
- Информационный блок размещается в свободной части графика, без стрелки к точке, если она не нужна для однозначности.

```python
filled = ax.contourf(x, y, z, levels=18, cmap="viridis", extend="both")
lines = ax.contour(x, y, z, levels=10, colors="black", linewidths=0.5, alpha=0.6)
ax.clabel(lines, fmt="%.2f", fontsize=7)
fig.colorbar(filled, ax=ax, pad=0.025, label="КПД нетто, %")
ax.plot(x_opt, y_opt, "*", ms=13, color="#C00000",
        markeredgecolor="white", markeredgewidth=0.8)
```

## Столбчатые диаграммы

- Короткие подписи категорий переносятся на две строки.
- Число помещается внутрь высокого столбца белым полужирным шрифтом; над низким — чёрным.
- Информационный блок располагается сверху слева или справа, не закрывая столбцы.

## Формулировки для научной работы

- Используйте: «расчётная модель», «справочные данные», «относительная ошибка», «сопоставление результатов».
- Не используйте в подписях рисунков: «заказчик», «заказчиковские данные», «vs заказчик».
- Формула относительной ошибки: `δ = (расчёт − справочное значение) / справочное значение × 100 %`.

## Проверка перед публикацией

1. Подписи, легенда и цветовая шкала находятся внутри холста.
2. Единицы указаны и одинаковы в данных, осях и подписи рисунка.
3. Цвета различимы при чёрно-белой печати благодаря разным маркерам/линиям.
4. PNG имеет 300 dpi, а PDF и SVG содержат редактируемый текст.
5. Размер файла остаётся `5 × 3` дюйма после экспорта.
