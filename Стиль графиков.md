# Стиль графиков

Стандарт применяется к графикам моделей He–Xe. Оформление воспроизводит референсы: крупная типографика Times New Roman, рамка осей со всех сторон, внутренние засечки, светлая сетка, насыщенные линии и белые информационные блоки.

## Холст и экспорт

Каждый одиночный график создаётся на холсте `900 × 540 px`.

```python
FIGSIZE = (9.0, 5.4)

fig, ax = plt.subplots(figsize=FIGSIZE)
fig.savefig(output_dir / 'имя_графика.png', dpi=100, facecolor='white')
fig.savefig(output_dir / 'имя_графика.svg', facecolor='white')
plt.close(fig)
```

Не использовать `bbox_inches='tight'`: он меняет заданный формат изображения.

## Глобальные параметры Matplotlib

Перед построением рисунков вызвать:

```python
from matplotlib.ticker import AutoMinorLocator

def set_publication_style():
    plt.rcParams.update({
        'font.family': 'Times New Roman',
        'font.size': 16,
        'mathtext.fontset': 'stix',
        'axes.linewidth': 1.6,
        'axes.titlesize': 22,
        'axes.labelsize': 22,
        'xtick.labelsize': 16,
        'ytick.labelsize': 16,
        'legend.fontsize': 14,
        'xtick.direction': 'in',
        'ytick.direction': 'in',
        'xtick.top': True,
        'ytick.right': True,
        'pdf.fonttype': 42,
        'ps.fonttype': 42,
        'svg.fonttype': 'none',
    })
```

Текст в SVG должен оставаться редактируемым (`svg.fonttype='none'`).

## Оси, деления и сетка

Применять к каждой оси после задания данных:

```python
def format_axes(ax, grid=True):
    ax.xaxis.set_minor_locator(AutoMinorLocator())
    ax.yaxis.set_minor_locator(AutoMinorLocator())
    ax.tick_params(which='major', length=7, width=1.4, pad=5)
    ax.tick_params(which='minor', length=3.5, width=1.0)
    if grid:
        ax.grid(True, which='major', color='0.75', alpha=0.32, lw=0.8)
```

Единицы измерения указываются в подписи оси. Заголовок формулирует содержание рисунка, а не повторяет единицы.

## Легенды и информационные блоки

Легенда располагается в свободной области внутри поля графика, с белым непрозрачным фоном и тонкой серой прямоугольной рамкой:

```python
def legend(ax, **kwargs):
    return ax.legend(
        frameon=True, facecolor='white', edgecolor='0.55',
        framealpha=0.96, fancybox=False, **kwargs,
    )

legend(ax, loc='best')
```

Информационный блок также имеет белый фон и серую скруглённую рамку:

```python
ax.text(
    0.03, 0.96, info_text, transform=ax.transAxes,
    va='top', fontsize=15,
    bbox=dict(facecolor='white', edgecolor='0.35', boxstyle='round,pad=.3'),

```

## Контурные карты

Применять цветовую карту `viridis`; изолинии — чёрные полупрозрачные. Оптимум — красная звезда с белой обводкой.

```python
filled = ax.contourf(x_grid, y_grid, z, levels=18,
                     cmap='viridis', extend='both')
lines = ax.contour(x_grid, y_grid, z, levels=10, colors='black',
                   linewidths=0.7, alpha=0.65)
ax.clabel(lines, fmt='%.1f', fontsize=11)
ax.plot(x_opt, y_opt, '*', color='#c00000', ms=18,
        mec='white', mew=1.0, zorder=5)

colorbar = fig.colorbar(filled, ax=ax, pad=0.025)
colorbar.set_label('КПД нетто, %', fontsize=20)
colorbar.ax.tick_params(labelsize=14)
```

## Столбчатые диаграммы

Использовать голубую палитру для потерь и красный цвет `#c00000` для ключевой полезной мощности. У высоких столбцов число размещается внутри белым полужирным шрифтом, у низких — над столбцом чёрным полужирным шрифтом.

```python
bars = ax.bar(labels, values,
              color=['#8cc0df', '#7fb3d5', '#4d8cbd', '#c00000', '#8cc0df'],
              edgecolor='0.25', linewidth=1.0)

for bar, value in zip(bars, values):
    inside = value > 0.25
    ax.text(
        bar.get_x() + bar.get_width() / 2,
        value / 2 if inside else value + 0.03,
        f'{value:.3f}', ha='center',
        va='center' if inside else 'bottom',
        fontsize=16, fontweight='bold',
        color='white' if inside else 'black',
    )
```

Категории с длинными названиями переносятся на две строки через `\n`.
